# Sai Joshi Nallagatla — AI Engineer Portfolio

A responsive, dark-themed personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Live site
After enabling GitHub Pages, publish from the `main` branch / root folder:
`https://saijosh1108.github.io/sai-joshi-portfolio/`

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and footer year

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then **Save**.

## Customize
Review the project links, skill levels, education dates, and contact details before sharing. Skills marked with an asterisk are learning areas rather than claims of production experience.
